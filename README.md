## Evaluation

Le module propose une évaluation reposant sur la remise de rendus intermédiaires et la production d'un rendu final.

| Évaluation                                                              | Poids | Description                                        |
|---------------------------|-----------------|-----------------------------|
| La base de données                                   | 2pts   | Un fichier excel ou csv au format base de données |
| Présentation de la base de données | 3pts   | Présentation de la base de données : sources, différentes variables...             |
| Statistiques descriptives                                    | 5pts   | Production des premiers indicateurs et leur interprétation |
| Statistiques bivariées                       | 8pts   | Production de stats, choix du test,  hypothèses, interpétations                            |
| Figures                      | 2pts   | Production de figures pour illustrer vos données et vos analyses                            |
